# AskNearby

**Just say what you're looking for.** An AI-powered store locator: type
"a location with a men's department and free parking near Columbus" and get
a map and synced list of matching stores.

Status: scaffold (2026-07-04). The weekly build plan lives in
[docs/ROADMAP.md](docs/ROADMAP.md); target demo ~mid-August 2026.

## How it works (the one-paragraph version)

A language model does exactly one job: translate the sentence into a typed
`SearchQuery` (a single forced tool call). The database — Postgres + PostGIS
over a first-party store dataset — produces the results; the UI renders them
deterministically on a map with a synced list. Both the AI vendor and the
maps vendor sit behind thin ports: swapping Anthropic → Gemini or adding a
second maps provider is a config change plus one adapter, and an eval
harness scores every model on the same golden queries (accuracy, latency,
cost).

All location data is synthetic (a fictional retail brand) generated by a
deterministic seed, so evals and demos are reproducible.
